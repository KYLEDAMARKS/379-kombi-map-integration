# 379 KOMBI map integration

Source for the map integration changes used by 379 Performance.

**Credit:** the map engine is Robert Nisipeanu's [idrive-apps](https://github.com/robertnisipeanu/idrive-apps), including **waze-on-cluster 0.6.0** and **cluster-render 0.2.0**. It was not written by 379. The native release binaries were used unchanged.

Download and extract **379-map-integration-source.zip** for the matching upstream source, configuration patches, 379 map installer, control helper, map-view code, build instructions and original licenses. See **CHANGES.md** for the changes and **PROVENANCE.json** for versions and checksums.

This repository covers the map integration. It does not contain unrelated 379 features, customer records, credentials, vehicle backups or BMW firmware. It is not an assertion about the licensing of every component in the broader product.
